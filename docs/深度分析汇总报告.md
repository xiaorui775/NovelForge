
### 3.2 设计亮点 — ChapterSummary

**结构化章节摘要** 是项目的核心创新设计：

```python
class ChapterSummary(Base):
    # 结构化摘要字段（JSON 字符串存储）
    events: Mapped[Optional[str]]              # 事件列表
    character_states: Mapped[Optional[str]]    # 角色状态变化
    unresolved_hooks: Mapped[Optional[str]]   # 未回收伏笔
    resolved_hooks: Mapped[Optional[str]]      # 已回收伏笔
    timeline: Mapped[Optional[str]]           # 时间线
    locations: Mapped[Optional[str]]           # 地点变化
    narrative_threads: Mapped[Optional[str]]   # 叙事线索

    # 元数据
    word_count_at_summary: Mapped[int]         # 生成时的字数
    is_stale: Mapped[bool]                      # 标记是否过期
    generated_at: Mapped[datetime]
```

**设计优点**:
- `is_stale` 标记实现智能更新，内容变化后自动重新生成
- `word_count_at_summary` 可追溯性，对比当前字数判断是否过期
- `character_states` 支持跨章角色状态追踪
- `unresolved_hooks` 是伏笔管理的核心数据结构

### 3.3 数据模型待改进项

| 问题 | 影响 | 建议 |
|------|------|------|

## 7. 代码质量深度审计与修正案例

### 7.1 🔴 P0 级别问题

#### 问题 1: 系统完全无认证

**影响**: 任何人均可访问/修改数据
**修复方案**:

```python
# backend/app/dependencies/auth.py
from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer
from jose import JWTError, jwt

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/auth/login")

async def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        user_id: str = payload.get("sub")
        if user_id is None:
            raise HTTPException(status_code=401, detail="Invalid token")
    except JWTError:
        raise HTTPException(status_code=401, detail="Invalid token")
    return user_id

# 在路由中使用
@router.get("/projects")
async def list_projects(
    user_id: str = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    return await project_service.list_by_user(db, user_id)
```

#### 问题 2: API 密钥同步解密阻塞事件循环

**当前代码** (`backend/app/utils/encryption.py`):

```python
def decrypt_api_key(encrypted_key: str) -> str:
    return _get_fernet().decrypt(encrypted_key.encode()).decode()

# 在 AdapterFactory 中被调用
create() -> AdapterFactory -> decrypt_api_key -> 🔴 同步阻塞
```

**修复**:

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor

_key_executor = ThreadPoolExecutor(max_workers=4)

async def decrypt_api_key_async(encrypted_key: str) -> str:
    loop = asyncio.get_event_loop()
    return await loop.run_in_executor(
        _key_executor,
        lambda: _get_fernet().decrypt(encrypted_key.encode()).decode()
    )

# 缓存解密后的密钥 (推荐)
from functools import lru_cache

_key_cache = {}

def decrypt_api_key_cached(encrypted_key: str) -> str:
    if encrypted_key not in _key_cache:
        _key_cache[encrypted_key] = _get_fernet().decrypt(encrypted_key.encode()).decode()
    return _key_cache[encrypted_key]
```

```python
def extract_json(raw: str, field_hint: str | None = None) -> dict | list:
    if not raw or not raw.strip():
        raise ValueError("AI 返回内容为空")
    
    text = raw.strip()
    
    # 策略 1: code fence
    for pattern in [r'```(?:json)?\s*(\{[\s\S]*?\})\s*```', 
                     r'```(?:json)?\s*(\[[\s\S]*?\])\s*```']:
        match = re.search(pattern, text)
        if match:
            try:
                return json.loads(match.group(1))
            except json.JSONDecodeError:
                pass
    
    # 策略 2: 修复常见 JSON 错误
    cleaned = _repair_json(text)
    try:
        return json.loads(cleaned)
    except json.JSONDecodeError:
        pass
    
    raise ValueError("AI 返回格式异常，无法提取 JSON")

def _repair_json(text: str) -> str:
    # 去除尾部逗号
    text = re.sub(r',\s*([}\]])', r'\1', text)
    # 修复单引号为双引号
    text = re.sub(r"(?<!\\)'", '"', text)
    # 去除注释
    text = re.sub(r'//.*$', '', text, flags=re.MULTILINE)
    return text
```
